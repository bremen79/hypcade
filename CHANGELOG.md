# Changelog

A short history of Hypcade. The [modification record](android/MODIFICATIONS.md)
describes the current differences from upstream Hypseus Singe.

## v0.2

- Improved user interface.
- More reliable ROM-derived moves, Max score and Fewest moves policies, and Watch Mode.
- Game difficulty and Space Ace skill selection, with its dedicated bezel.
- Faster game-text rendering and consistent CRT filtering of game graphics and text.
- Smaller packages and improved build tooling and documentation.

## v0.1

- Initial Android arcade adaptation of Hypseus Singe 3.0.2.
- SD-card game libraries, arcade controller setup and a secondary mobile interface.
- Hardware and ARM NEON video decoding, with GPU CRT filtering.
- Move guidance, audio cues, scoreboards and persistent settings and saves.
