## Arcade guidance

The move-window decoders adapt RAM-layout knowledge and code from Jeff Nyman's
[laser-vault](https://github.com/jeffnyman/laser-vault), commit
`1f12c84dfabf3c8e5d028c8804b2f96678c798fa`, under GNU GPL version 3 or later (Copyright (C) 2026 Jeff Nyman).
See `app/jni/arcade_guidance.cpp` and `../tools/offline-moves/`.
Move-assistance tables are derived from analysis and execution of user-supplied
ROMs. They contain gameplay input, timing and state metadata. Commercial ROM
images and laserdisc media are not included. Rights in the original games remain
with their respective holders. Hypcade's software licence does not grant rights
to third-party game content. Use only game files you are legally authorised to
use.

The offline generator uses the pinned source subset under
`tools/offline-moves/vendor/`; that subset's CPU/player code is not included in
the APK. Complete GPL text is in the project's LICENSE file.

## Android MPEG-2 NEON acceleration

`android/app/jni/mpeg2_idct_neon.c` adapts the bundled libmpeg2 `idct.c`,
Copyright 2000–2003 Michel Lespinasse and 1999–2000 Aaron Holtzman, GPL-2.0-or-later;
the Android additions are GPL-3.0-or-later. Original notices are retained in the
file. Motion compensation and dispatch additions are GPL-3.0-or-later. The pinned
libmpeg2 archive remains unchanged. No additional decoder library is bundled.
Intrinsics follow the [Arm ACLE reference](https://arm-software.github.io/acle/neon_intrinsics/advsimd.html).

## Offline move extractor (host tools)

The pinned upstream README explicitly grants GPL-3.0-or-later; that grant is
retained in `tools/offline-moves/vendor/NOTICE`.

`tools/offline-moves/vendor/` contains the minimal Z80/Cinematronics/LD-V1000,
AY-8910 and ROM/ZIP source subset from the same Jeff Nyman laser-vault revision
above, under GPL-3.0. Its local changes and file hashes are recorded in
`vendor/provenance.json`, and its full license is included in `vendor/LICENSE`.
The tools decode ROM scene/step policies, validate selected input timings
against a simultaneous no-input simulation, and independently replay complete
games before packaging the complete ROM policies as shared pools with strategy
index lists. The structural exporter retains windows not visited by those games. Required
zero-score actions are retained. This is a
laptop build tool, not linked into or packaged in the APK. See
`tools/offline-moves/README.md` for its source and reproduction instructions.

The PR-7820 adapter in `tools/offline-moves/board_adapter.c` adapts Hypseus/DAPHNE
protocol code by Warren Ondras (2003), based on work by Matt Ownby and Mark
Broadhead, under GPL-2.0-or-later. Its notices remain in the source.
The European-board verifier extracts methods from `src/game/laireuro.cpp`
(Mark Broadhead, 2001–2007; DirtBagXon, 2024) and `src/ldp-in/vp932.cpp`
(Mark Broadhead, 2005–2007), retaining their GPL-2.0-or-later notices in the
repository. The host adaptations are GPL-3.0-or-later. No commercial ROM
program bytes or character graphics are distributed with the move policies.

## zfast-crt shader

Copyright (C) 2017 Greg Hogan (SoltanGris42), GPL-2.0-or-later.
Source: https://github.com/libretro/glsl-shaders, commit
`8aab13063da6ad3ae928e886c41e13fa363f4d89`, `crt/shaders/zfast_crt.glsl`.
The original file and SHA-256 are in `shaders/`; the GLES2 adaptation is
`app/jni/android_crt_shader.h`. Hypcade uses mild fixed parameters and places
the mask in output pixels. One GPU pass filters the composed video, ROM game
text and recorded moves. Added score/lives overlays, FPS, subtitles and cabinet
bezels are drawn afterward without the effect.
The GPLv2 text is included in `licenses/libmpeg2-COPYING.txt`.
